# Castar Server на iPhone

Комплект выпуска **0.11.14**. Используйте архивы сервера и приложения из [одного выпуска](https://github.com/krislechy/Castar/releases/tag/v0.11.14). Проверьте загруженные файлы по `SHA256SUMS.txt` перед установкой или обновлением.

Повторная категоризация покупки использует API сервера 0.11.13. Перед обновлением сохраните резервную копию SQLite.

Архив `Castar-Server-ios-arm64.tar` содержит сервер, службу наблюдения и приложение Castar для статуса и журналов. Сервер и приложение проверены на iPhone SE первого поколения с iOS 15.7 и rootless-jailbreak. Нужны ARM64, iOS 15 или новее, rootless-окружение в `/var/jb` и доступ к SSH с возможностью выполнять команды через `sudo`. Среда .NET и библиотеки SQLite и QR входят в архив.

## Установка

Скачайте архив из [GitHub Releases](https://github.com/krislechy/Castar/releases). На iPhone понадобятся `bash`, `ldid`, `launchctl`, `uicache`, `tar` и базовые утилиты rootless-окружения. Используйте адрес iPhone в Wi-Fi и порт вашего SSH-сервера.

На Windows в PowerShell выполните команды, подставив адрес iPhone.

```powershell
scp -P 22 .\Castar-Server-ios-arm64.tar mobile@IPHONE_IP:.
ssh -p 22 mobile@IPHONE_IP
```

В сеансе SSH распакуйте архив и установите его.

```sh
work=$(mktemp -d "$HOME/castar-install.XXXXXXXX")
tar -xf "$HOME/Castar-Server-ios-arm64.tar" -C "$work"
sudo /var/jb/usr/bin/bash "$work/install.sh"
```

Если `ldid` установлен вне стандартного пути, передайте его абсолютный путь.

```sh
sudo /var/jb/usr/bin/env LDID=/absolute/path/to/ldid /var/jb/usr/bin/bash "$work/install.sh"
```

Откройте Castar на iPhone. Приложение показывает состояние сервера и последние строки журнала. Кнопка **Остановить** останавливает Castar до явного запуска. Кнопка **Перезапустить** также запускает остановленный сервер. Наблюдатель проверяет доступность API в фоне и перезапускает сервер при сбое. После перезагрузки доступность службы зависит от повторной активации jailbreak.

При исправной работе наблюдатель проверяет API каждые 25 секунд, а регистрацию службы в launchd подтверждает при запуске и раз в 5 минут. После ошибки он повторяет проверку через 3 секунды. Три последовательные ошибки запускают восстановление, а отсутствующая служба запускается при первом обнаружении. Интервал между попытками восстановления составляет не менее 30 секунд. Журналы проверяются на размер каждые 5 минут. Кнопки управления работают через локальный сокет и доступны между проверками.

## Подключение Windows-клиента

После запуска сервера откройте **Ключи API** в Castar на iPhone. Экран показывает адрес сервера, адрес для Windows и действующие ключи. Первоначальный ключ, включая ключ существующей установки, можно скопировать. Новый ключ показывается при выпуске. При необходимости выпустите отдельный ключ для каждого клиента и отзовите его из списка.

### Сертификат HTTPS

Распакуйте архив на Windows. В PowerShell 7.4 или новее подставьте текущий IPv4 iPhone и выполните команды.

```powershell
.\New-HttpsCertificate.ps1 -Address IPHONE_IP -OutputDirectory .\castar-https
Import-Certificate -FilePath .\castar-https\castar-iphone.cer -CertStoreLocation Cert:\CurrentUser\Root
ssh -p 22 mobile@IPHONE_IP 'umask 077; mkdir -p ~/.castar-tls'
scp -P 22 .\castar-https\https.pfx .\castar-https\https.env mobile@IPHONE_IP:.castar-tls/
ssh -p 22 mobile@IPHONE_IP
```

В сеансе на iPhone установите файлы и перезапустите Castar.

```sh
sudo install -o mobile -g mobile -m 0600 "$HOME/.castar-tls/https.pfx" /var/jb/etc/castar/https.pfx
sudo install -o mobile -g mobile -m 0600 "$HOME/.castar-tls/https.env" /var/jb/etc/castar/https.env
sudo /var/jb/usr/bin/launchctl kickstart -k system/org.castar.server
```

Закройте SSH. Экран **Ключи API** показывает адрес `https://IPHONE_IP:5443` и ключи. Введите адрес и выбранный ключ в Windows-клиенте. Проверка `Invoke-WebRequest https://IPHONE_IP:5443/health` должна вернуть HTTP 200.

Операции с бюджетом и события SignalR используют тот же адрес HTTPS и ключ API. Windows-клиент обновляет данные при повторном подключении.

Для подключения с другого компьютера импортируйте на нём тот же публичный файл `castar-iphone.cer`. При смене IP или истечении срока сертификата выпустите новый комплект и повторите настройку. Храните `https.pfx` и `https.env` вместе с защищённой резервной копией сервера.

## SQLite и Telegram

- База находится в `/var/jb/var/lib/castar/castar.sqlite`. При первом запуске сервер создаёт её автоматически.
- В Windows-клиенте откройте **Настройки → Сервер → Создать резервную копию**, чтобы скачать согласованный снимок SQLite по HTTPS. Для полного восстановления сохраните отдельно файлы ключей, настроек и TLS.
- Реестр ключей находится в `castar.sqlite.keys.json` рядом с базой. Включите его в резервную копию, чтобы сохранить выданные ключи и список отозванных.
- Для переноса существующей базы остановите Castar с обеих сторон. Загрузите согласованную копию SQLite на iPhone, сохраните резервную копию имеющейся базы и установите перенесённый файл с владельцем `mobile:mobile` и правами `0600`. Если исходная база использует WAL, перед копированием закройте все соединения и выполните checkpoint либо создайте копию командой SQLite `.backup`.
- После подключения Windows-клиента откройте **Настройки → Сервер**, чтобы задать токен Telegram, включить бота и выбрать поставщика чеков. Налоговая Сербии использует анонимную авторизацию. Для ФНС России нажмите **Установить данные для входа**, заполните форму и сохраните настройки сервера. Один токен Telegram должен обслуживаться одним процессом.
- Бот ждёт обновления Telegram до 50 секунд за запрос. При сбоях пауза между повторами растёт со случайным разбросом до 5 минут. Если Telegram возвращает `Retry-After`, бот выдерживает указанную паузу.
- Интервал повторной загрузки чеков задаётся в Windows-клиенте в поле **Настройки → Сервер → Повтор чека, мин**. Запросы в очереди сохраняются в SQLite при перезапуске службы.
- Список валют и валюту ручного добавления задайте в Windows-клиенте в разделе **Настройки → Сервер**. Telegram подставляет эту валюту автоматически. Чтобы выбрать другую разрешённую валюту, добавьте её код после суммы, например `Хлеб 150 RSD` или `/income Оплата 100 EUR`. Валюта для просмотра сумм и итогов задаётся в **Настройки → Приложение → Отображаемая валюта**.
- Уведомления Telegram настраиваются по каждому пользователю. В Windows-клиенте откройте профиль пользователя двойным щелчком в **Настройки → Пользователи** и сохраните значение флажка **Отправлять уведомления**.
- Сервер хранит полученные исторические курсы в SQLite. Для загрузки недостающих курсов iPhone использует исходящее HTTPS-подключение. [Frankfurter](https://frankfurter.dev/)
- Изменения действуют сразу и сохраняются в `castar.sqlite.settings.json` рядом с базой. Храните резервные копии этого файла с ограниченным доступом. Пока секреты не заданы через клиент, сервер использует соответствующие значения из `/var/jb/etc/castar/server.env`. Остальные параметры перечислены в [инструкции Castar Server](https://github.com/krislechy/Castar/blob/main/Castar.Server/DEPLOYMENT.md).

## Обновление

При переходе с 0.8.0 версия 0.9.0 однократно преобразует сохранённое белградское время операций в UTC. Это происходит во время проверочного запуска. Часовой пояс просмотра задаётся в Windows-клиенте в **Настройки → Приложение → Часовой пояс**.

Нажмите **Обновить сервер** на экране состояния Castar на iPhone или в разделе **Настройки → Сервер** в Windows-клиенте. Служба обновления загружает iPhone TAR из GitHub Releases, проверяет SHA-256 и версию и показывает ход скачивания. Во время установки сервер перезапускается. После успешной проверки приложение показывает установленную версию.

Конфигурация, HTTPS-сертификат, SQLite и ключи API сохраняются. При ошибке проверочного запуска установщик восстанавливает прежние файлы сервера и данные. Для первой установки службы обновления используйте полный TAR и шаги из раздела **Установка**. Полный архив также можно установить вручную.

Журналы сервера и наблюдателя находятся в `/var/jb/var/log/castar`, журнал обновления — в `/var/jb/var/lib/castar-control/update.log`. Состояние служб можно посмотреть через SSH.

```sh
sudo launchctl print system/org.castar.watchdog
sudo launchctl print system/org.castar.server
sudo launchctl print system/org.castar.updater
sudo launchctl print system/org.castar.updater-recovery
```

## Сборка архива

Для сборки из исходников используйте PowerShell 7.4 или новее, .NET SDK из `global.json`, Zig 0.15.2, LLVM `ld64.lld`, CMake и Ninja. Передайте предоставленный отдельно iPhoneOS SDK для iOS 15 или новее. SDK нужен на машине сборки. Сохраните ссылки SDK на файлы `.tbd` при переносе между файловыми системами.

```powershell
$bundle = Join-Path $PWD 'out/castar-ios-arm64'
./Castar.Server.iOS/Build.ps1 -OutputPath $bundle -IosSdk $iosSdk -Zig $zig -Ld64 $ld64
tar -cf ./out/Castar-Server-ios-arm64.tar -C $bundle .
$appFiles = 'CastarControl.app', 'CastarControl.entitlements.plist', 'DEPLOYMENT.md' |
    ForEach-Object { Join-Path $bundle $_ }
Compress-Archive -LiteralPath $appFiles -DestinationPath ./out/Castar-Control-ios-arm64.zip
Get-FileHash ./out/Castar-Server-ios-arm64.tar, ./out/Castar-Control-ios-arm64.zip -Algorithm SHA256
```

`$iosSdk`, `$zig` и `$ld64` указывают на каталог SDK и исполняемые файлы Zig и LLD. Если CMake, Ninja или .NET отсутствуют в PATH, передайте `-CMake`, `-Ninja` или `-DotNet`. Сборка загружает и проверяет пакеты NuGet и исходники ZXing-C++. Атрибуции входят в каталог `notices`.
