# База данных Castar

Castar.Server хранит данные в SQLite и обслуживает HTTP API и Telegram-бота. Один сервер может принимать запросы нескольких WPF-клиентов. При первом запуске сервер создаёт файл `data/castar.sqlite` рядом с исполняемым файлом. Задайте `Database__SqlitePath` для размещения файла в постоянном томе или другом каталоге.

## Архивы прежней базы

Для переноса старых данных до обновления сервера используйте одноразовый импорт из тега `v0.3.0`. Команда и поддерживаемые схемы описаны в [инструкции того выпуска](https://github.com/krislechy/Castar/blob/v0.3.0/DataBase/README.md#перенос-из-sql-server-в-sqlite). После сверки данных укажите полученный файл в `Database__SqlitePath`.
