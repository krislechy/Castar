# Castar

Castar — приложение WPF для учёта доходов и покупок. Оно принимает покупки и доходы через Telegram, загружает позиции фискальных чеков по QR-коду и показывает доходы по выбранному периоду.

## Установка и обновление

Скачайте `Castar-Setup-win-x64.exe` из [последнего выпуска](https://github.com/krislechy/Castar/releases/latest). Установщик рассчитан на 64-разрядную Windows 10 версии 2004 или новее и включает среду .NET 11.

Для обновления откройте **Настройки → Обновления Castar → Проверить обновления**. Castar проверит наличие стабильного выпуска, сверит SHA-256 установщика по данным GitHub и запустит его после подтверждения. Устанавливайте поверх той же копии, чтобы сохранить доступ к сохранённым зашифрованным полям. При переносе старого XML в другую папку повторно введите токен и пароли.

## Хранилище

Новая установка по умолчанию создаёт SQLite в `%LOCALAPPDATA%\Castar\castar.sqlite`. Приложение хранит пользовательские настройки в `%LOCALAPPDATA%\Castar\Castar.Settings.xml`. Если рядом с исполняемым файлом уже есть старый `Castar.Settings.xml`, Castar использует его и сохраняет SQL Server для конфигураций до добавления выбора хранилища.

Для работы с SQL Server задайте экземпляр и имя базы либо путь к подключаемому MDF. Примените [скрипт схемы](DataBase/UpgradeCastar.sql) к выбранной базе. По умолчанию используется аутентификация Windows. Для локального SQL Server с самоподписанным сертификатом можно включить параметр доверия к сертификату.

Для переноса откройте **Настройки → База данных**, укажите источник SQL Server, выключите бота и остановите другие процессы, записывающие в исходную базу. Нажмите **Перенести данные из SQL Server в SQLite**, выберите новый файл и перезапустите Castar. Проверенные архивы и различия форматов описаны в [документации БД](DataBase/README.md).

## Telegram и чеки

В настройках укажите токен бота и включите его. Отправьте `/me` в личном чате, чтобы узнать Telegram ID, затем добавьте пользователя с этим ID в Castar. Получатели уведомлений о доходах и покупках определяются списком пользователей приложения.

В разделе **Получение чеков** выберите провайдера. Для Сербии отправьте боту фото QR-кода или саму ссылку с чека. Провайдер обращается к [публичному сервису TaxCore](https://tap.suf.purs.gov.rs/help/view/145107305/Verify-invoice-via-verification-URL-with-JSON-response/en-US). Для провайдера ФНС России заполните ИНН и пароль. Новые провайдеры подключаются через `IReceiptProvider`.

## Сборка

Установите [.NET SDK 11](https://dotnet.microsoft.com/en-us/download/dotnet/11.0) и выполните на Windows `dotnet build Castar.sln -c Release`. Публикация тега вида `vX.Y.Z`, совпадающего с `Version` в `Castar/Castar.csproj`, запускает сборку установщика и выпуск на GitHub.
