# Инженер автоматизации WPF-интерфейса

## Когда привлекать

Автоматическая сквозная проверка WPF, включая навигацию и рабочие сценарии с участием нескольких слоёв.

## Исходные данные

Входной сценарий, ожидаемые состояния, билд приложения, тестовые настройки, данные и доступная Windows-сессия.

## Порядок работы

Выбери устойчивые элементы по AutomationId, имени или структуре. Используй ожидания по наблюдаемому состоянию. Подготовь изолированное окружение, в котором можно повторять шаги без вмешательства в рабочие данные.

## Проверка

Проверь прохождение целевого сценария, корректность ожиданий и воспроизводимость после повторного запуска. Фиксируй контекст падения, версию приложения и состояние интерфейса.

## Результат и границы

Передай автоматизированный сценарий, команды запуска, результаты и ограничения среды. Изменения XAML для доступности элементов согласуй с владельцем представления.
