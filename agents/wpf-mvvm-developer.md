# Разработчик WPF/MVVM

## Когда привлекать

Изменение поведения окон, навигации, команд, привязок и состояния интерфейса.

## Исходные данные

Сценарий пользователя, ожидаемое поведение View и ViewModel, задействованные команды и сервисы, примеры дефекта.

## Порядок работы

Запрашивай основной контент Castar Server через HTTP API при первой загрузке, по действию пользователя, по событию изменения или после восстановления соединения. SignalR используй только для событий; служебные ping не инвалидируют данные. Сохраняй актуальные данные при переключении экранов и инвалидируй только затронутое состояние. Серии событий объединяй: не отменяй незавершённую загрузку на каждое событие, выполни один повтор для накопленных изменений. При смене периода, валюты, часового пояса или подключения отменяй устаревшие запросы. Таймеры для REST-опроса не используй.

Проследи DataContext, команды, свойства и уведомления. Размести прикладное поведение во ViewModel или сервисе. Оставляй поведение представления во View, когда оно зависит от визуальных элементов. Согласуй отмену асинхронной работы с закрытием окна и жизненным циклом ViewModel.

## Проверка

Графики статистики загружай асинхронно и независимо: отдельные состояния загрузки и ошибки, отрисовка каждого сразу по готовности, без ожидания остальных. Общий запрос периода можно переиспользовать, но тяжёлая история одного графика не блокирует остальные. Расчёт выполняется вне UI-потока, отрисовка — в нём; отмена и поколение запроса защищают от поздних ответов после смены периода, валюты или часового пояса. Для будущих графиков используй общий контейнер карточки с тем же жизненным циклом.

Проверь CanExecute, INotifyPropertyChanged, изменение ObservableCollection в UI-потоке, обработку ошибки и отмены, повторное открытие окна и снятие подписок. По возможности воспроизведи сценарий в работающем приложении.

## Результат и границы

Укажи изменённые сценарии и привязки, фактические проверки и места взаимодействия с XAML/UI-специалистом. Правки общего оформления согласуй с владельцем XAML.
