Castar 0.8.0 обновляет настройки, уведомления и работу с историческими курсами.

- Настройки открываются поверх текущего раздела. В списке пользователей показаны аватары.
- Поля входа зависят от поставщика чеков. Сербская налоговая работает с анонимной авторизацией.
- Уведомления показывают автора, название и сумму операции. Карточки Castar используют аватар, если он доступен.
- В редакторе покупки можно сменить её валюту. Сумма и исходные данные фискального чека сохраняются.
- Доходы и расходы обновляются по событиям. Сервер сохраняет запрошенные исторические курсы в SQLite.
- Обновлены левое меню и общие отступы доходов, расходов и статистики.

## Windows-клиент

Для первой установки установите [.NET Desktop Runtime 11 для Windows x64](https://dotnet.microsoft.com/download/dotnet/11.0#desktop-runtime-11.0.0), затем запустите `Castar-win-x64.exe`. Для обновления откройте **Настройки → Обновления**. Castar скачает ZIP с отображением хода загрузки и сохранит настройки.

## Сервер

Доступны архивы для Windows x64, Linux x64, Linux ARM64 и iPhone ARM64. При первом запуске 0.8.0 сервер добавляет в SQLite таблицу кеша курсов. Управляемый сервер обновляется из Windows-клиента, а на iPhone также из приложения Castar.

`Castar-Server-ios-arm64.tar` содержит сервер, приложение, фоновые службы и инструкцию для iPhone с rootless-jailbreak. Отдельное приложение доступно в `Castar-Control-ios-arm64.zip`. Хеши файлов перечислены в `SHA256SUMS.txt`.
