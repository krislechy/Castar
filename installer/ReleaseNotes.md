Castar 0.11.9 добавляет категории доходов, расходов и товаров.

- Справочники доходов и расходов разделены и открываются рядом с кнопками добавления.
- Категории товаров можно назначать и подтверждать вручную. Автоматическая категоризация через Ollama или llama.cpp использует эти подтверждения перед обращением к локальной модели.
- Клиент поддерживает подключение к работающему провайдеру, управление локальным процессом, обнаружение моделей и выгрузку по таймеру.
- Обработка архива назначает категории товарам без категории и показывает прогресс и примерное время завершения.

## Windows-клиент

Для первой установки установите [.NET Desktop Runtime 11 для Windows x64](https://dotnet.microsoft.com/download/dotnet/11.0#desktop-runtime-11.0.0), затем запустите `Castar-win-x64.exe`. Для обновления откройте настройки Castar.

## Сервер

Доступны пакеты Windows x64, Linux x64, Linux ARM64 и iPhone ARM64. Перед обновлением создайте резервную копию. Сервер обновляет схему SQLite автоматически и сохраняет существующие операции.

[Установка и обновление на Windows и Linux](https://github.com/krislechy/Castar/blob/v0.11.9/Castar.Server/DEPLOYMENT.md) · [Установка и обновление на iPhone](https://github.com/krislechy/Castar/blob/v0.11.9/Castar.Server.iOS/DEPLOYMENT.md)

Серверный TAR для iPhone включает приложение управления, фоновые службы и инструкцию. Отдельный ZIP содержит приложение управления. Контрольные суммы приведены в `SHA256SUMS.txt`.
