Castar 0.11.5 уточняет сравнение расходов и упрощает просмотр операций.

- На графике «Скорость расходования бюджета» пунктир показывает историческое среднее накопленных расходов к каждому дню. Доступно сравнение за 1, 3, 6 и 12 предыдущих полных месяцев. Для коротких месяцев на недостающих днях берётся итог месяца.
- В левом списке расходов новые покупки теперь сверху.
- «Текущий остаток» отображается с двумя знаками после запятой.

## Windows-клиент

Для первой установки установите [.NET Desktop Runtime 11 для Windows x64](https://dotnet.microsoft.com/download/dotnet/11.0#desktop-runtime-11.0.0), затем запустите `Castar-win-x64.exe`. Для обновления откройте настройки Castar.

## Сервер

Доступны пакеты Windows x64, Linux x64, Linux ARM64 и iPhone ARM64. Перед обновлением создайте резервную копию. Сервер и клиент обновляются отдельно. Схема базы данных сохранена.

[Установка и обновление на Windows и Linux](https://github.com/krislechy/Castar/blob/v0.11.5/Castar.Server/DEPLOYMENT.md) · [Установка и обновление на iPhone](https://github.com/krislechy/Castar/blob/v0.11.5/Castar.Server.iOS/DEPLOYMENT.md)

Серверный TAR для iPhone включает приложение управления, фоновые службы и инструкцию. Отдельный ZIP содержит приложение управления. Все пакеты собраны из одной ревизии. Контрольные суммы приведены в `SHA256SUMS.txt`.
