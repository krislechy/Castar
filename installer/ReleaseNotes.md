Castar 0.5.0 добавляет прямое подключение к серверу iPhone по HTTPS, обновление сервера из клиента и управление настройками интеграций.

- Windows-клиент показывает состояние соединения и причину сбоя. Таблица пользователей доступна после подключения.
- Доходы и расходы синхронизируются через SignalR. Подключённый клиент получает события об изменениях.
- В настройках сервера можно управлять Telegram и обработкой чеков, менять токен бота, поставщика чеков и учётные данные ФНС.
- Приложение Castar на iPhone показывает адрес, состояние и журналы сервера. В нём можно перезапустить и остановить службу, выпустить или отозвать ключ API и запустить обновление.

## Windows-клиент

Для первой установки установите [.NET Desktop Runtime 11 для Windows x64](https://dotnet.microsoft.com/download/dotnet/11.0#desktop-runtime-11.0.0), затем запустите `Castar-win-x64.exe`. Для обновления установленного клиента откройте **Настройки → Обновления**. Клиент загружает `Castar-Update-win-x64.zip` и сохраняет настройки.

## Сервер

Доступны архивы Windows x64, Linux x64, Linux ARM64 и iPhone ARM64. Серверные архивы содержат среду выполнения. Для подготовки службы обновления при переходе с предыдущей версии используйте [инструкцию для Windows и Linux](https://github.com/krislechy/Castar/blob/v0.5.0/Castar.Server/DEPLOYMENT.md) или [инструкцию для iPhone](https://github.com/krislechy/Castar/blob/v0.5.0/Castar.Server.iOS/DEPLOYMENT.md). После настройки нажмите **Обновить сервер** в Windows-клиенте или на iPhone.

`Castar-Server-ios-arm64.tar` содержит сервер, фоновые службы, приложение и инструкцию для iPhone с rootless-jailbreak. `Castar-Control-ios-arm64.zip` содержит отдельную сборку приложения. Контрольные суммы всех архивов и установщика перечислены в `SHA256SUMS.txt`.
