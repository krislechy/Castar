Castar 0.10.3 ускоряет загрузку расходов и статистики, сохраняет очередь повторов чеков и выводит меню добавления покупки в Telegram.

- Запросы к временно недоступному поставщику чеков сохраняются в SQLite. Интервал повтора задаётся в настройках сервера.
- В Telegram доступны `/purchase` для добавления покупки и `/info` для просмотра команд и форматов ввода.
- Товары загружаются при выборе покупки. Сводка и статистика передаются в сжатом виде.
- В Windows-клиенте обновлены выбор владельца, панель настроек, отступы списков и редактор аватаров. В общем селекторе периода появилась кнопка текущего месяца.

## Windows-клиент

Для первой установки установите [.NET Desktop Runtime 11 для Windows x64](https://dotnet.microsoft.com/download/dotnet/11.0#desktop-runtime-11.0.0), затем запустите `Castar-win-x64.exe`. Для последующих обновлений используйте **Настройки → Обновления**.

## Сервер

Доступны пакеты Windows x64, Linux x64, Linux ARM64 и iPhone ARM64. Обновление добавляет очередь чеков и индексы дат в SQLite, а также удаляет прежнее поле категории товара. Перед ручным обновлением создайте резервную копию. Импорт истории из MDF/LDF запускается отдельно по инструкции.

[Windows и Linux](https://github.com/krislechy/Castar/blob/v0.10.3/Castar.Server/DEPLOYMENT.md) · [iPhone](https://github.com/krislechy/Castar/blob/v0.10.3/Castar.Server.iOS/DEPLOYMENT.md) · [Импорт истории](https://github.com/krislechy/Castar/blob/v0.10.3/DataBase/README.md)

Серверный TAR для iPhone включает приложение, фоновые службы и инструкцию. Отдельный ZIP содержит приложение. Контрольные суммы пакетов приведены в `SHA256SUMS.txt`.
