Castar 0.11.2 исправляет добавление дохода через Telegram и обновляет меню бота.

- В личном чате команда `/income` без аргументов запускает пошаговый ввод: источник, сумма, валюта и подтверждение сохранения.
- Текстовая команда принимает источник с пробелами, например `/income Оплата за проект 100 EUR`. Валюту можно опустить — используется валюта ручного добавления.
- `/cancel` отменяет активный ввод дохода или покупки. Справка `/info` описывает оба способа добавления дохода.

## Windows-клиент

Для первой установки установите [.NET Desktop Runtime 11 для Windows x64](https://dotnet.microsoft.com/download/dotnet/11.0#desktop-runtime-11.0.0), затем запустите `Castar-win-x64.exe`. Для последующих обновлений используйте **Настройки → Обновления Castar**.

## Сервер

Для исправления Telegram обновите сервер до 0.11.2. Доступны пакеты Windows x64, Linux x64, Linux ARM64 и iPhone ARM64. Перед обновлением создайте резервную копию. Сервер и клиент обновляются отдельно; схема базы данных не изменена.

[Windows и Linux](https://github.com/krislechy/Castar/blob/v0.11.2/Castar.Server/DEPLOYMENT.md) · [iPhone](https://github.com/krislechy/Castar/blob/v0.11.2/Castar.Server.iOS/DEPLOYMENT.md)

Серверный TAR для iPhone включает приложение, фоновые службы и инструкцию. Отдельный ZIP содержит приложение. Все пакеты собраны из одной ревизии 0.11.2. Контрольные суммы приведены в `SHA256SUMS.txt`.
