Castar 0.11.1 добавляет множественное выделение и итоги выбранных строк в доходах и расходах.

- Выделяйте доходы, покупки и товары с помощью Ctrl, Shift и Ctrl+A. Выделение учитывает текущий поиск.
- Сумма выбранных доходов и покупок отображается рядом с поиском, товаров — под их списком. В режиме исходных валют суммы сгруппированы по валюте; строки без валюты или исторического курса отмечаются отдельно.
- Обновлена компоновка сводок и кнопок добавления, добавлена иконка сводки расходов, убраны повторные заголовки разделов.

## Windows-клиент

Для первой установки установите [.NET Desktop Runtime 11 для Windows x64](https://dotnet.microsoft.com/download/dotnet/11.0#desktop-runtime-11.0.0), затем запустите `Castar-win-x64.exe`. Для последующих обновлений используйте **Настройки → Обновления Castar**. Настройки и данные сохраняются.

## Сервер

Доступны пакеты Windows x64, Linux x64, Linux ARM64 и iPhone ARM64. API и схема базы данных в этом выпуске не изменены. Перед ручным обновлением создайте резервную копию. Сервер и клиент обновляются отдельно.

[Windows и Linux](https://github.com/krislechy/Castar/blob/v0.11.1/Castar.Server/DEPLOYMENT.md) · [iPhone](https://github.com/krislechy/Castar/blob/v0.11.1/Castar.Server.iOS/DEPLOYMENT.md)

Серверный TAR для iPhone включает приложение, фоновые службы и инструкцию. Отдельный ZIP содержит приложение. Все пакеты собраны из одной ревизии 0.11.1. Контрольные суммы приведены в `SHA256SUMS.txt`.
