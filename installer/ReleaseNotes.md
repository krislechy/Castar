Castar 0.4.0 сохраняет общие настройки клиента при переходе со старого формата. Сервер использует SQLite и миграции EF Core.

- При наличии старого файла настроек клиент сохраняет параметры автозапуска и сворачивания в трей в новом формате.
- Сервер принимает существующий файл SQLite Castar. Перед обновлением остановите сервер и сделайте копию базы.
- Клиент обновляется из настроек и показывает ход загрузки.

## Первая установка Windows-клиента

Установите [.NET Desktop Runtime 11 для Windows x64](https://dotnet.microsoft.com/download/dotnet/11.0#desktop-runtime-11.0.0), затем запустите `Castar-win-x64.exe`. После установки укажите адрес сервера и API-ключ в настройках Castar.

## Переход с v0.2.0

Один раз установите .NET Desktop Runtime 11 x64 отдельно. Скачайте `Castar-Update-win-x64.zip`, распакуйте его во временную папку и полностью закройте прежний Castar. Откройте PowerShell в распакованной папке и выполните команду. Если Castar установлен по другому пути, укажите его каталог первым аргументом.

```powershell
.\Castar.Updater.exe "$env:LOCALAPPDATA\Programs\Castar" (Get-Location).Path
```

Помощник обновит файлы в существующем каталоге, сохранит настройки и запустит новую версию. Следующие выпуски устанавливаются из раздела обновлений в Castar.

## Сервер

`Castar-Server-win-x64.zip` и `Castar-Server-linux-x64.tar.gz` содержат сервер со своей средой выполнения. Порядок запуска, подключение по HTTPS и перенос базы описаны в [инструкции по развёртыванию](https://github.com/krislechy/Castar/blob/v0.4.0/Castar.Server/DEPLOYMENT.md).
