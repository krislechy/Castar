Castar 0.11.6 добавляет финансовую подушку в статистику и выбор целого месяца.

- «Финансовая подушка» показывает запас средств в месяцах, ориентировочную дату исчерпания и среднемесячные расходы в валюте отображения. Для расчёта доступны 3, 6 и 12 полных месяцев, по умолчанию — 3.
- График «Скорость расходования бюджета» сравнивает расходы с предыдущими 3, 6 или 12 полными месяцами.
- В общем селекторе периода можно выбрать целый календарный месяц для расходов, доходов и статистики.

## Windows-клиент

Для первой установки установите [.NET Desktop Runtime 11 для Windows x64](https://dotnet.microsoft.com/download/dotnet/11.0#desktop-runtime-11.0.0), затем запустите `Castar-win-x64.exe`. Для обновления откройте настройки Castar.

## Сервер

Доступны пакеты Windows x64, Linux x64, Linux ARM64 и iPhone ARM64. Перед обновлением создайте резервную копию. Сервер и клиент обновляются отдельно. Схема базы данных сохранена.

[Установка и обновление на Windows и Linux](https://github.com/krislechy/Castar/blob/v0.11.6/Castar.Server/DEPLOYMENT.md) · [Установка и обновление на iPhone](https://github.com/krislechy/Castar/blob/v0.11.6/Castar.Server.iOS/DEPLOYMENT.md)

Серверный TAR для iPhone включает приложение управления, фоновые службы и инструкцию. Отдельный ZIP содержит приложение управления. Все пакеты собраны из одной ревизии. Контрольные суммы приведены в `SHA256SUMS.txt`.
