Castar 0.6.0 исправляет импорт чеков сербской налоговой и добавляет валюту бюджета.

- TaxCore разбирает позиции из журнала чека и проверяет их итог. Дедупликация сохраняет совместимость с ранее импортированными чеками.
- Клиент показывает исходные суммы и пересчитывает расходы и доходы в выбранную валюту по историческому курсу. Исходные значения сохраняются в SQLite. Покупки и доходы без известной валюты остаются доступны в списках.
- Валюту новой ручной записи можно указать в клиенте для дохода и добавить после суммы в боте Telegram. Настройки Castar используют общий выпадающий список.

## Windows-клиент

Для первой установки установите [.NET Desktop Runtime 11 для Windows x64](https://dotnet.microsoft.com/download/dotnet/11.0#desktop-runtime-11.0.0), затем запустите `Castar-win-x64.exe`. Для обновления клиента откройте **Настройки → Обновления**. Castar скачает ZIP и сохранит настройки.

## Сервер

Доступны серверные архивы для Windows x64, Linux x64, Linux ARM64 и iPhone ARM64. При запуске новой версии сервер добавляет поля валюты дохода и даты фискального чека в SQLite. Управляемый сервер обновляется из Windows-клиента, а на iPhone также из приложения Castar. [Развёртывание Windows и Linux](https://github.com/krislechy/Castar/blob/v0.6.0/Castar.Server/DEPLOYMENT.md) · [Установка и обновление на iPhone](https://github.com/krislechy/Castar/blob/v0.6.0/Castar.Server.iOS/DEPLOYMENT.md)

`Castar-Server-ios-arm64.tar` содержит сервер, приложение, фоновые службы и инструкцию для iPhone с rootless-jailbreak. Отдельная сборка приложения доступна в `Castar-Control-ios-arm64.zip`. Контрольные суммы всех файлов перечислены в `SHA256SUMS.txt`.
