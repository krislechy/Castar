Castar 0.11.4 обновляет статистику и списки доходов и расходов.

- В расходах теперь видна разница с предыдущим периодом. Сравнение использует исторические курсы на даты операций.
- В статистике тепловая карта стоит последней. «Итог за период» выделяет положительный результат зелёным, отрицательный красным. На графике скорости расходования оттенок линии зависит от того, насколько фактические расходы отклонились от среднего за три предыдущих месяца.
- У графиков появились иконки на круглых подложках. В списке доходов подсвечивается строка под указателем. Подтверждения удаления используют общий стиль диалогов.

## Windows-клиент

Для первой установки установите [.NET Desktop Runtime 11 для Windows x64](https://dotnet.microsoft.com/download/dotnet/11.0#desktop-runtime-11.0.0), затем запустите `Castar-win-x64.exe`. Для обновления откройте настройки Castar.

## Сервер

Доступны пакеты Windows x64, Linux x64, Linux ARM64 и iPhone ARM64. Перед обновлением создайте резервную копию. Сервер и клиент обновляются отдельно. Схема базы данных сохранена.

[Установка и обновление на Windows и Linux](https://github.com/krislechy/Castar/blob/v0.11.4/Castar.Server/DEPLOYMENT.md) · [Установка и обновление на iPhone](https://github.com/krislechy/Castar/blob/v0.11.4/Castar.Server.iOS/DEPLOYMENT.md)

Серверный TAR для iPhone включает приложение управления, фоновые службы и инструкцию. Отдельный ZIP содержит приложение управления. Все пакеты собраны из одной ревизии. Контрольные суммы приведены в `SHA256SUMS.txt`.
