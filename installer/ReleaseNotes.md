Castar 0.7.0 добавляет статистику бюджета, редактирование расходов и настройки уведомлений.

- В «Статистике» доступны итоги, графики доходов и расходов и расходы по заполненным категориям. Период задаётся общим селектором доходов и расходов.
- Двойной щелчок по покупке или позиции открывает редактор. Контекстное меню позволяет удалить покупку или позицию с подтверждением и открыть исходный QR для копирования.
- Настройка «Отображаемая валюта» задаёт валюту расчётов. При пересчёте под суммой показана сумма в исходной валюте. Пропуски валюты или курса отмечены у расходов.
- Сервер задаёт допустимые валюты и валюту ручного добавления для клиента и Telegram. В настройках пользователя можно выключить автоматические уведомления бота.
- Windows-клиент поддерживает системные уведомления или карточки Castar с выбором угла и количества. Щелчок по карточке открывает операцию.
- Провайдеры чеков сохраняют точный исходный QR через общий импорт. Идентификаторы прежних чеков подходят для дедупликации.

## Windows-клиент

Для первой установки установите [.NET Desktop Runtime 11 для Windows x64](https://dotnet.microsoft.com/download/dotnet/11.0#desktop-runtime-11.0.0), затем запустите `Castar-win-x64.exe`. Для обновления откройте **Настройки → Обновления**. Castar скачает ZIP и сохранит настройки.

## Сервер

Доступны архивы для Windows x64, Linux x64, Linux ARM64 и iPhone ARM64. Сервер при первом запуске 0.7.0 добавляет в SQLite поля редактирования чеков и настройку уведомлений Telegram. Управляемый сервер обновляется из Windows-клиента, а на iPhone также из приложения Castar.

`Castar-Server-ios-arm64.tar` содержит сервер, приложение, фоновые службы и инструкцию для iPhone с rootless-jailbreak. Отдельное приложение доступно в `Castar-Control-ios-arm64.zip`. Хеши файлов перечислены в `SHA256SUMS.txt`.
