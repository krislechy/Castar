Castar 0.9.0 добавляет резервные копии SQLite, ручные покупки и выбор часового пояса.

- В расходах можно создавать покупки с товарами, менять владельца и просматривать его аватар. Фискальные правки отмечаются, исходные данные можно скопировать и показать как QR-код.
- Настройки открываются списком разделов. Редактор аватара показывает круглый кадр, а ввод дат и чисел использует общие контролы Castar.
- Клиент обновляет данные по событиям SignalR и сохраняет актуальные данные при переключении разделов. На оси сумм статистики используются k и M.
- Сервер сохраняет время операций в UTC и использует исходную календарную дату для исторического курса. Документация описывает импорт архива MDF/LDF в SQLite с сохранением сумм в RUB.
- Вернулись настройки значков Telegram. Для тестового чата доступна команда /testpurchase.

## Windows-клиент

Для первой установки установите [.NET Desktop Runtime 11 для Windows x64](https://dotnet.microsoft.com/download/dotnet/11.0#desktop-runtime-11.0.0), затем запустите `Castar-win-x64.exe`. Для обновления откройте **Настройки → Обновления**. Клиент скачает ZIP с отображением хода загрузки и сохранит настройки.

## Сервер

Доступны архивы для Windows x64, Linux x64, Linux ARM64 и iPhone ARM64. При переходе с 0.8.0 сервер преобразует существующие белградские локальные даты в UTC. Для ручного обновления сохраните копию базы заранее.

`Castar-Server-ios-arm64.tar` содержит сервер, приложение, фоновые службы и инструкцию для iPhone с rootless-jailbreak. Отдельное приложение доступно в `Castar-Control-ios-arm64.zip`. Хеши опубликованы в `SHA256SUMS.txt`.
