Castar 0.11.8 обновляет тепловую карту расходов.

- Карточки дней и месяцев показывают суммы и интенсивность расходов. Нажатие на месяц открывает его карту по дням.
- Ползунок на градиентной шкале меняет чувствительность цвета. Настройка сохраняется отдельно для карты по дням и по месяцам.
- Убрана рамка вокруг всей карты при наведении и рамка вокруг цветовой шкалы. Переход от синего к фиолетовому стал контрастнее.

## Windows-клиент

Для первой установки установите [.NET Desktop Runtime 11 для Windows x64](https://dotnet.microsoft.com/download/dotnet/11.0#desktop-runtime-11.0.0), затем запустите `Castar-win-x64.exe`. Для обновления откройте настройки Castar.

## Сервер

Доступны пакеты Windows x64, Linux x64, Linux ARM64 и iPhone ARM64. Перед обновлением создайте резервную копию. Сервер и клиент обновляются отдельно. Схема базы данных сохранена.

[Установка и обновление на Windows и Linux](https://github.com/krislechy/Castar/blob/v0.11.8/Castar.Server/DEPLOYMENT.md) · [Установка и обновление на iPhone](https://github.com/krislechy/Castar/blob/v0.11.8/Castar.Server.iOS/DEPLOYMENT.md)

Серверный TAR для iPhone включает приложение управления, фоновые службы и инструкцию. Отдельный ZIP содержит приложение управления. Все пакеты собраны из одной ревизии. Контрольные суммы приведены в `SHA256SUMS.txt`.
