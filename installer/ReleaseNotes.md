Castar 0.11.0 обновляет оформление Windows-клиента, работу с периодами и графики бюджета.

- Общий выбранный период используется в доходах, расходах и статистике. Его можно менять в календаре и быстро переключать на текущий месяц.
- В статистике появились динамика остатка, тепловая карта расходов и сравнение месячных расходов. Текущий остаток рассчитан по всей истории до сегодняшнего дня и показан отдельно от выбранного периода.
- Доходы, расходы и настройки получили общее оформление, явные меню действий и состояния загрузки. Суммы сохраняют исходную валюту и исторические курсы.
- Запрос начального остатка передаёт сгруппированную историю без потери точности округления. Загрузка графиков объединяет изменения по событиям и сохраняет уже показанные данные во время обновления.
- Клиент хранит рассчитанные данные графиков в ограниченном кэше памяти с TTL и объединяет одинаковые одновременные запросы. Изменения бюджета и подключения сбрасывают кэш; на диске и в серверной БД он не хранится.
- Наблюдатель сервера iPhone реже выполняет проверки при исправной работе. Подключение Telegram использует длительное ожидание и увеличивает паузу после ошибок.
- Улучшены журналирование и диагностика ошибок клиента и сетевых подключений.

## Windows-клиент

Для первой установки установите [.NET Desktop Runtime 11 для Windows x64](https://dotnet.microsoft.com/download/dotnet/11.0#desktop-runtime-11.0.0), затем запустите `Castar-win-x64.exe`. Для последующих обновлений используйте **Настройки → Обновления Castar**. Настройки и данные сохраняются.

## Сервер

Доступны пакеты Windows x64, Linux x64, Linux ARM64 и iPhone ARM64. Перед ручным обновлением создайте резервную копию. Сервер и клиент обновляются отдельно; новый клиент сохраняет совместимость с предыдущим форматом получения операций.

[Windows и Linux](https://github.com/krislechy/Castar/blob/v0.11.0/Castar.Server/DEPLOYMENT.md) · [iPhone](https://github.com/krislechy/Castar/blob/v0.11.0/Castar.Server.iOS/DEPLOYMENT.md) · [Импорт истории](https://github.com/krislechy/Castar/blob/v0.11.0/DataBase/README.md)

Серверный TAR для iPhone включает приложение, фоновые службы и инструкцию. Отдельный ZIP содержит приложение. Все пакеты собраны из одной ревизии 0.11.0. Контрольные суммы приведены в `SHA256SUMS.txt`.
