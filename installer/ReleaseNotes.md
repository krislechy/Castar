Первый выпуск Castar для Windows x64 с установщиком.

- .NET 11 и EF Core 11. SQLite для новых установок и перенос данных из SQL Server через настройки.
- Импорт чеков в Telegram по фото QR или ссылке налоговой Сербии. Провайдер можно выбрать в настройках.
- Команда проверки обновлений в настройках скачивает установщик из GitHub Releases и проверяет SHA-256.

Настройка базы данных, перенос архивов и запуск бота описаны в [README](https://github.com/krislechy/Castar/blob/main/README.md).
